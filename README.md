# KeyHarbor for Mac

KeyHarbor is a menu bar launcher for apps and websites. Open it from the KeyHarbor menu bar icon or press Control–Option–Command–K. Add an app or website with Add Item. An item can have its own shortcut. Search, select an item using the arrow keys, and press Return to open it.

For help, report an issue at https://github.com/Kerita/keyharbor-support/issues. Include your macOS and KeyHarbor versions. Do not include private URLs, personal file paths, or backups.

- 简体中文：点按菜单栏图标或按 Control–Option–Command–K 打开。遇到问题，请在 Issues 中反馈。
- 日本語：メニューバーのアイコンまたは Control–Option–Command–K で起動できます。お問い合わせは Issues からどうぞ。
